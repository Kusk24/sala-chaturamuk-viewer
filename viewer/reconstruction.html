MethodMulti-view photogrammetry: feature matching → sparse SfM → dense MVS → mesh → texture baking (Object Capture, full detail).
Input146 eye-level photographs, 4032×3024, with sky masked out per image so no sky is reconstructed as geometry.
Post-processingGround trim, sliver removal, hole closing, Taubin smoothing. The central roof crossing was never visible in any photograph and is modelled as a fitted cross-gable — the one part of this mesh that is not measured.
Versus IBRThe IBR viewer synthesizes in-between viewpoints from photographs and has no geometry; this mesh can be viewed from any angle but inherits every occlusion of the capture.
